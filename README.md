# SD Voice AI Lab

MVP de laboratório para chamadas de voz com IA, preparado para integração futura com o SD Dialer.

## Estrutura

- `frontend/` — interface Next.js e APIs
- `worker/` — agente de voz Python/LiveKit
- `supabase/` — schema da base de dados
- `DEPLOY_ORACLE.md` — instruções de deployment

Consulte os ficheiros `.env.example` para configurar as variáveis necessárias. Nunca faça commit de segredos reais.
